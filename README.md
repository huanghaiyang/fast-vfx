# FastVFX · Vue + Three.js 游戏特效工坊

一个跑在浏览器里的实时游戏特效编辑器：粒子、参数化建模、程序化贴图、关键帧动画，一键导出 **Godot 4** 可直接使用的资源包。

```
Vue 3 + TypeScript + Vite + Three.js
```

## 快速开始

```bash
npm install
npm run dev      # http://127.0.0.1:5273
npm run build    # 产物在 dist/
```

首次打开会自动载入「烈焰」预设并循环播放。编辑内容会每 0.9s 自动存到 localStorage，重开可恢复；`保存项目` 导出 `.vfx.json`，`打开` 载入。

## 功能

### 预设库（25 套，按分类分组）

- **火焰**：烈焰、烈焰喷射、火球术、火焰冲击波、烈焰风暴、岩浆喷发、灼烧地面、火焰护体、龙息、灰烬爆破、火刃斩
- **元素**：冰霜新星、雷电冲击、陨石坠落、剧毒领域、冰晶碎裂（实体八面体冰晶爆散 + 落地弹跳 + 冷光闪爆）
- **战斗**：冲击爆炸、斩击刀光
- **法术**：奥术法阵、圣光护盾、暗影侵蚀、虚空裂隙、治疗光环
- **演示**：子发射演示（喷柱火种触地溅射火星 + 飘散余烬寿命碎裂成尘，同时演示速度/自旋曲线与色标透明度）、冲击爆点（4×4 序列帧爆闪 + 带地面反弹的实体碎石）

每套预设都带完整对象、材质、粒子参数与关键帧轨道，载入即可播放，也可在时间轴上继续改。

### 粒子系统

自研 `InstancedBufferGeometry` 粒子渲染，单发射器上限 20000 颗，CPU 模拟 + GPU 实例化绘制：

- 发射：速率、爆发（数量 / 间隔）、单次发射时长、寿命区间
- 形状：点 / 球体（可仅表面）/ 长方体 / 锥形（带锥角）/ 圆面 / 圆环
- 运动：初速区间、主方向、扩散角、重力、阻尼、湍流场（强度 + 尺度）、径向外推、绕 Y 漩涡
- 外观：基础尺寸 + 生命内尺寸曲线、生命内速度倍率曲线、生命内自旋倍率曲线、生命内颜色渐变（色标颜色 + 色标透明度）、亮度、淡入/淡出
- **实体几何粒子**：`渲染 → 渲染模式` 切到「实体几何」后不再用 billboard 贴片，而是 `InstancedMesh` 实例化真实网格——碎片（四面体）/ 碎石（十二面体）/ 晶体（八面体）/ 方块，逐粒子翻滚旋转，颜色仍走生命渐变（透明度折进颜色做衰减）。适合碎石、冰晶、残骸这类有体积感的碎块。实体模式下贴图与序列帧不生效（面板会提示）。
- 序列帧：`渲染 → 序列帧贴图` 打开后按 `cols×rows` 把整张贴图切成帧，`iProg` 属性带每颗粒子的生命进度，默认「随生命播放并停在末帧」，也可切成按 fps 循环；开着序列帧时会自动关掉逐粒子的 UV 镜像（否则整图翻转会把格子拼错）
- 碰撞：`碰撞` 区块可开地面碰撞（世界 y 高度可调），撞地按 `反弹` 反射法向速度、按 `摩擦保留` 衰减切向速度，反弹速度低于 0.08 m/s 会直接贴地；勾 `撞地直接消失` 则走与寿命结束相同的清理逻辑，同时也会触发子发射的「触地」条件
- 生命曲线：三条曲线都按「当前生命进度 0→1」采样。尺寸曲线缩放大小；速度/自旋曲线是倍率（1 = 原始值，末端拉到 0 就是减速停住 / 停转）；色标透明度与淡入淡出相乘，可做「出生半透明 → 中段最浓 → 化掉」
- 子发射：某对象可以指定另一粒子对象作为接收方，在自己粒子**寿命结束**或**触地（世界 y < 0）**时，把位置与按「速度继承」缩放后的速度注入过去，附带数量与方向扩散角。注入事件带时间戳，因此拖时间轴快进回放也能在正确的时刻爆开，而不是全部挤在 0 秒
- 旋转：初始角区间、自旋速度、朝向速度对齐、沿速度拉伸（屏幕空间投影）
- 多火头：**簇**（同时存在的火头数量，1 = 单簇）+ **簇散布**（火头在发射面上的散开半径），配合**范围**（发射半径）与**尺寸**，构成火焰类特效的四个主参数，且全部可打关键帧

### 渲染细节（去「纸片感」的几个关键处理）

- **逐粒子随机**：每颗粒子带独立种子，尺寸抖动 0.82~1.24 倍、亮度抖动 ±14%、UV 四向随机镜像，避免整片粒子像同一张贴图复制
- **竖向贴图不翻转**：`flame` / `beam` 这类「底厚顶尖」的方向性贴图会被识别为竖向贴图（`uAxis=1`、`uFlipV=0`）——不做 UV 纵向镜像、不参与 0~360° 自由旋转，`+Y` 轴对齐速度方向，并以贴图底边为锚点向上生长、根部做软化淡出；横向拖尾贴图（`spark` / `slash`）仍按 `+X` 对齐，各向同性贴图保留四向随机镜像
- **闪烁**：加色粒子的亮度按 7.3Hz 正弦起伏，火焰有呼吸感而不是静止贴图
- **高清丝状火舌贴图**：`flame` 单独走 1024 分辨率，域扭曲让火舌随高度摆动，三条高斯火舌 + 双频丝状断口 + 竖向包络（底厚顶尖），底部带白热核，远看是连续火焰、近看有丝
- **白热核心**：贴图高密度处向白热过曝（烟雾层除外），配合 ACES tone mapping + UnrealBloom 出真实的亮心
- **克制的泛光**：`UnrealBloom` 用 `0.4 / 0.28 / 0.86`（强度 / 半径 / 阈值），只让真正过曝的核心发光，不会把高密度粒子区糊成整屏红光
- **地面暖光**：`glowDisc` 给火焰类特效垫一层会淡出的加色圆盘，火光才会「照在地上」
- 发光模型建议走加色 + 低不透明度，靠 bloom 出光，而不是纯色实体

- 渲染：粒子贴图（完整贴图列表的可视化网格选择：上方按贴图类别切页，每类含「原始 + 24 变形」，另有「上传」分类放自传图，点缩略图即套用并自动把变形贴图登记进项目）、加色 / 透明 / 正片叠底、数量上限、不透明度
- 范围 / 簇 / 尺寸这三个参数有关键帧轨道时，面板显示的是**当前播放头采样值**，改值会直接写到该时刻的关键帧上（不再被轨道覆盖而「调了没反应」）；没轨道才改对象本身

### 建模（内置参数化）

14 种几何体：立方体、球体、多面体、圆环、环面纽结、圆锥、圆柱、胶囊、平面、圆环面片、圆盘、弧形刀光、晶体、岩石。可调节尺寸 / 半径 / 管径 / 厚度 / 扫掠角 / 分段，晶体与岩石支持噪声形变与种子。材质含基础色、自发光、发光强度、金属度、粗糙度、不透明度、贴图、UV 重复、线框、平面着色、加色混合。

每种几何体都带 **8 个变种**（检查器「几何体 → 变种」一排按钮，任意类型都能套）：

| 变种 | 做法 | 典型用法 |
| --- | --- | --- |
| 原始 | 基础图元 | 光球、冲击环 |
| 岩石 | 硬棱噪声（\|noise\| 造棱线） | 碎石、陨石块、地刺 |
| 坑洼 | 随机球冠挖坑（6~12 个坑，方向/深度随机） | 被砸过的地面、陨坑球 |
| 鼓包 | 低频正弦起伏 | 熔岩球、肉块、气泡 |
| 尖刺 | 高频噪声的正向极值放大 | 冰棱球、尖刺壳 |
| 环纹 | 沿 Y 轴层积波纹 | 层积岩、熔岩涌浪 |
| 扭曲 | 绕轴扭转（角度随高度） | 藤蔓、漩涡、拧过的金属 |
| 棱面 | 顶点吸附粗网格 | 低模块面石、晶体 |
| 抻长 | 各向异性拉长 + 噪声 | 陨石、子弹、水滴 |

变种在几何生成阶段就作用在顶点上（不是贴图或缩放伪装），同一形状配不同变种是真正不同的网格；变种会随 GLB 一起导出到 Godot。

### 导入 GLB / 外部模型

「模型」页上面的「＋ 上传 GLB / GLTF」可以直接把外部模型纳入资源库，支持多选、单个 ≤ 60MB。

- **落盘位置**：上传的文件写入项目内 `data/models/`（文件名按 `slug` 规范化，重名自动加 `-2 / -3` 后缀）。这些文件跟项目一起走版本管理，换机器、换分支都还在，不依赖浏览器缓存。
- **只读扫描**：把现成的 `.glb` 丢进 `data/models/` 再刷新页面，也会被自动收进资源库（`/api/models/list`），不需要重新上传。
- **IndexedDB 只做临时兜底**：只有在 dev server 的落盘接口不可用（静态部署、接口异常）时，文件才临时存进 IndexedDB，界面会提示「临时存储」；自动存档与导出时也不会把模型二进制塞进 JSON，避免项目文件膨胀。
- **分类**：岩石 / 植被 / 建筑 / 道具 / 角色 / 特效件 / 其他，新增时按文件名猜一次，之后可在资源列表或检查器里随时改；列表按分类分组。
- **添加实例**：在资源列表点条目即拉进场景，几何体类型为「导入」，检查器里只显示资产信息与分类，其余参数化几何参数与变种按钮隐藏。
- **导出**：导入的模型会原样并进导出的 `models.glb`，节点名与编辑器里的对象名一致，GDScript 运行时按 `fxIndex` 找节点。

一个限制：`.gltf` 只是 JSON 外壳，外挂的 `.bin` 与贴图不会被一起带走，所以上传 `.gltf` 请先在 DCC 或 `gltf-pipeline` 里打包成单文件 `.glb`。

### 贴图

### 动画

- 通道：位置 / 旋转 / 缩放（模型与粒子均可）+ 透明度；粒子另有 **范围 / 簇 / 尺寸** 三个参数轨道
- 打帧：检查器里参数名前的 ◆（灰=无轨道，橙=已有轨道）点一下就在播放头写关键帧；时间轴每行显示该属性所有关键帧，可直接拖拽改时间
- 时间轴：播放头拖拽预览、关键帧拖拽改时间、双击删除、轨道单行管理
- 自动 K 帧：开启后拖动变换手柄或在检查器改数值，自动在播放头写入关键帧
- 播放：循环 / 单次，时长可调

### 关键帧查看与帧间比对

时间轴上的每个 ◆ 都能点选：点一下选中单帧，右侧检查器整块切成「关键帧」面板；按住 **Shift 再点同一条轨道上的另一帧**，两帧进入比对模式（换到别的轨道会重置为单帧）。

面板里能做三件事：

- **查**：轨道对象与属性、该轨道的关键帧总数、插值方式（平滑 / 线性，可切换）、播放头当前时刻的采样值；下面还有一排「1·0.00s / 2·0.80s …」的全部帧快捷条，点即跳。**只选一帧时**还会出「该帧属性快照」——把该对象所有轨道在这个时刻的采样值一列列摊开（当前轨道那行高亮），再补一行贴图 / 发射率 / 亮度 / 混合等静态参数，等于直接看这一帧的完整形态。
- **改**：每帧的时间（毫秒级，改完轨道自动按时间重排）与该帧的数值（向量轨是 x/y/z 三格，标量轨是单格），删帧、定位、上一帧 / 下一帧都在这里。
- **比**：选中两帧后自动出「帧间比对」，左右两栏并排 ——

```
A · 0.00s        变化项        B · 0.90s
 1.000         缩放 · x          1.051  +0.051
 1.000         缩放 · y          1.118  +0.118
 0.160            范围           0.340  +0.180 (+112.5%)
 3.000             簇            5.000  +2.000 (+66.7%)
```

左栏是 A 帧、右栏是 B 帧，中间是属性名与正负号着色的 Δ（标量额外给相对变化 %）。**只列真正变化的项**：把该对象所有轨道分别在两帧时间点采样，|Δ| < 1e-4 的行直接不显示；两帧完全一致时提示「两帧数值完全一致（只有时间不同）」。下方补 Δt，有位置轨道时再给位移距离与平均速度。

两帧如果不是相邻帧，面板会提示「中间还隔着 N 帧」，代表比的是整段跨度；两帧时间重合时也会提示 Δ 无意义。

### 位移轨迹在舞台上的显示

任何带 `position` 轨道（≥2 帧）的对象，视口里都会画出它的运动轨迹：按当前插值逐段采样成的折线 + 每个关键帧位置的点标 + 一个跟着播放头走的球标。

- 选中对象的轨迹是青色、加粗、关键帧点更大；其余对象的轨迹是暗橙色，不抢主体
- 右上角 **◈ 路径** 按钮可整体开关，不影响导出，也不写进项目文件

### 视口

OrbitControls 环绕、TransformControls 移动/旋转/缩放、点选对象、选中包围盒、网格地面、UnrealBloom 泛光、ACES 色调映射、FPS 统计。

### 成片输出（PNG 序列 / WebM）

顶部 **⤓ 导出 ▾** 下拉菜单有三条出口，帧率可在菜单里切 24 / 30 / 60：

- **PNG 序列**：按当前机位逐帧 `renderFrame(t)` 渲染整段时长，`toBlob` 后打包成 `<项目名>_png_<fps>fps_<帧数>frames.zip`，帧名 `frame_0001.png` 顺序编号，zip 内附 `frames.json`（fps / 帧数 / 时长 / 分辨率）。逐帧渲染会临时停掉播放并在结束后恢复，不会改动时间轴状态
- **WebM 成片**：`canvas.captureStream(fps)` + `MediaRecorder`（优先 VP9，回退 VP8），录制前临时关闭 `循环`、把时间轴拉回 0 并清空所有发射器，录满「时长 + 0.3s」余量后停止并还原循环开关
- 画布用 `preserveDrawingBuffer: true`，否则 WebGL 缓冲在合成后就被清掉，`toBlob` / `captureStream` 会拿到空白帧

## 导出 Godot 4

点击顶部 **导出 ▾ → Godot 工程包**，生成 `<slug>_godot.zip`：

```
<slug>/
  vfx.json          # 粒子参数 / 变换 / 动画（引擎中立）
  vfx_runtime.gd    # 运行时构建脚本（@tool，编辑器内可预览）
  models.glb        # 网格（GLTF，含材质）
  textures/*.png    # 粒子与模型贴图
  <slug>.tscn       # 可直接打开的场景（挂载 vfx_runtime.gd）
  README.md         # 包内说明与差异清单
```

使用步骤：把整个文件夹拖进 Godot 项目根目录 → 等编辑器导入 `models.glb` 与贴图 → 打开 `<slug>.tscn` 运行，或：

```gdscript
var fx = preload("res://<slug>/<slug>.tscn").instantiate()
add_child(fx)
fx.position = Vector3(0, 0, 0)
```

映射关系：

| FastVFX | Godot 4 |
| --- | --- |
| 粒子发射器 | `GPUParticles3D` + `ParticleProcessMaterial` |
| 发射形状 | `EMISSION_SHAPE_POINT / SPHERE / BOX / RING` |
| 初速 / 扩散 / 重力 / 阻尼 | `initial_velocity_*` / `spread` / `gravity` / `damping_*` |
| 尺寸曲线 | `scale_curve`（CurveTexture） |
| 颜色渐变 + 淡入淡出 + 色标透明度 | `color_ramp`（GradientTexture1D，16 点采样；alpha = 色标透明度 × 淡入淡出 × 不透明度） |
| 加色混合 | `BLEND_MODE_ADD` + 无光照 + 关闭深度写入 |
| 内置几何体 | GLB（导入失败时回退到 Box/Sphere/Torus/Cylinder/Capsule/PlaneMesh） |
| 关键帧 | `AnimationPlayer`（position / quaternion / scale / transparency） |

已知差异（导出包内 README 也会列出）：

- 逐粒子速度拉伸在 Godot 中退化为 `particle_flag_align_y` 朝向，无法精确还原拉伸倍率
- 发射器的局部持续时长、按间隔重复爆发不参与导出
- 湍流为近似参数映射
- **范围 / 簇 / 尺寸** 三条参数轨道仅编辑器内生效：Godot 粒子没有对应属性，导出时使用静态值并在包内 README 列入 warnings（要动画化请在 Godot 里改发射半径或 `scale`）
- **生命内速度 / 自旋倍率曲线**：Godot 侧只导出静态初速与角速度，曲线不随包走（warnings 会点出哪些对象用了）
- **子发射**：运行时脚本不支持跨发射器注入，需在 Godot 里用 `GPUParticles3D.sub_emitter` 自行接
- **序列帧**：导出只带整张图集，Godot 侧要自己写图集 UV 动画（或用 ShaderMaterial 按生命进度取格子）
- **地面碰撞反弹**：Godot 侧需自行实现，导出参数只作参考
- **实体几何粒子**：Godot 侧要换成 `GPUParticles3D` + Mesh（四面体/十二面体/八面体/方块对应内置图元），billboard 贴片着色器不适用
- 相机机位不随特效导出
- 变种几何随 GLB 完整导出；只有在 GLB 导入失败、退回 `godotPrimitive` 图元时，变种会退化成基础图元

```

  core/
    types.ts        数据模型（EffectDoc / ParticleDoc / ModelDoc / Track）

    capture.ts      PNG 序列打包 / WebM 录制
```

## 分享 / 调试用 URL 参数

`?preset=fire&t=1.6` 直达某个预设并停在该时间点；`?help=1` 打开指南；`?tab=model` 切到模型页；`?sel=2` 选中第 3 个对象；`?texvar=4` 把场景里所有基础贴图换成对应第 4 号变形；`?variant=3` 把所有模型换成第 3 号几何变种；`?asset=rock-test.glb` 直接把 `data/models` 里的该模型加进场景；`?key=0:0,1` 选中第 1 条轨道的第 1、2 个关键帧并进入比对。
